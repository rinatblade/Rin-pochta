# Rin-pochta

Android-приложение для отслеживания посылок **Китай → Казахстан** в одном месте:
Pinduoduo, AliExpress, Cainiao, Казпочта, курьеры по Казахстану.

<img src="icon-512.png" width="128" align="right">

## Возможности

- Добавление по трек-номеру или номеру заказа (Pinduoduo / AliExpress) — тип номера определяется автоматически
- **Один маршрут из нескольких номеров**: китайский трек + казахстанский трек объединяются в одну ленту событий с этапами (Принят → Отправлен → Таможня КНР → В пути → Прибыл в КЗ → Доставка → Вручено)
- Несколько источников одновременно: Cainiao и Казпочта (без ключей), 17TRACK и AfterShip (с API-ключом, вводится в настройках); видно, какой источник ответил
- Проверка номера на 11 сайтах (17TRACK, Cainiao, Казпочта, AfterShip, Parcels, Track24, CDEK, AliExpress, Yanwen, 4PX, YunExpress) во встроенном браузере
- 40 тем (20 тёмных и 20 светлых, с градиентами) и 40 русских шрифтов
- Данные хранятся только на телефоне

## Важно про заказы Pinduoduo и AliExpress

Номер **заказа** — это не номер **посылки**. Магазины не отдают логистику вне своих приложений, поэтому для заказа приложение подсказывает, где взять трек-номер (в приложении магазина), и вы добавляете его кнопкой «+ Добавить номер».

## Сборка

APK собирается автоматически в GitHub Actions при каждом push в `main` и публикуется в **Releases** (`Rin-pochta.apk`).
Шрифты скачиваются во время сборки скриптом `scripts/fetch-fonts.js` и упаковываются в приложение; если это не удалось, шрифты подгружаются из Google Fonts при наличии интернета.

Локально: `gradle assembleRelease` (нужны Android SDK и JDK 17).

## Структура

- `app/src/main/java/kz/rin/pochta/MainActivity.java` — оболочка WebView, HTTP-мост, встроенный браузер
- `app/src/main/assets/www/` — интерфейс (`app.js`, `app.css`, `themes.js`)
